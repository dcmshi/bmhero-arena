## Traps that cost real time (new this session)

The 08-05 and 08-04 lists still apply — read them there.

- **PowerShell's `-Matches` parameter shadows the automatic `$Matches`**
  regex variable — using `-match` anywhere in `net-soak.ps1` tries to store
  a hashtable into an `[int]`. Parsing goes through `[regex]::Match`.
- **PowerShell variables are case-INSENSITIVE**: `$rv = Start-Process`
  silently clobbered the `$RV` binary path; symptom read as "missing
  binary". Process handles are named `*Proc` in net-soak for this reason.
- **The bash CMake picks for ctest ships a sed whose BRE `\(...\)` capture
  groups silently don't work** — green by hand, red under ctest. Field
  slicing (`tr`/`cut`) instead; the comment in `run_mesh_test.sh` has the
  repro one-liner.
- **MinGW-built exes off an MSYS2 PATH die at load (0xC0000135) with NO
  output** — reads exactly like "the host never printed a code". net-soak
  prepends the runtime dir itself, same as gate.ps1 does for gcc.
- **Measure before gating on a threshold**: "stalls < 1/min" was written
  before stalls were ever measured; they turned out to be a fixed startup
  transient, making the criterion unattainable AND wrong-shaped. One
  measurement run replaced it with a fraction that scales.
- **A one-shot UDP push is a silent lobby killer**: PEER_INTRO/PAIR_ROUTE
  were fire-once; at 1% loss ~30% of 4P lobbies would have died on a 30s
  timeout. Loopback tests can never see this class — it was caught only by
  review asking "what retransmits this?". The recovery rides the idempotent
  retry paths, unit-tested to mutation-kill.
