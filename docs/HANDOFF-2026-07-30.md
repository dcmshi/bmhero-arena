## Traps that cost real time (carried forward — all still live)

1. **A gate can assert your own assumption and never fail.** Pair it with
   something you did not choose. (Counter-example done right: §8.23 restored
   the frame-rising gate precisely because the implementation now makes it
   *possible* to fail.)
2. **A call-graph search answers "is this used?", never "does this exist?".**
   For an asset, enumerate and render it.
3. **A failed build leaves the previous exe and the soak tests it happily.**
   Always confirm `BUILD OK` before trusting a probe result.
4. **Validate an instrument before trusting it.** §8.17.
5. **Measure the geometry, not the player.** §8.15.
6. **Probe timing is not tick timing.** Input poll runs ~45 ahead of the sim
   tick; the 180-tick countdown silently drops early buttons. §8.22.
7. **Literal `\n` in C string content** breaks the build. Use the Edit tool
   for C strings, not shell heredocs.
8. **MSYS2 gcc fails silently** without its own `bin` on PATH; the PS scripts
   prepend it.
9. **Export name collisions:** a `syms.ld` export must not share a name with
   the native implementation — follow the `arena_export_*` shim convention.
   Also: patch externs must match `lib/bmhero/include/functions.h` (it already
   declares most game funcs — a conflicting local extern is a build error).
   And an export called WITHOUT its `DECLARE_FUNC` compiles with only an
   implicit-declaration warning — for an f32-returning export the caller then
   reads `$v0` instead of `$f0` (garbage). Treat those warnings as errors
   (§8.24 found two).
10. **New `ARENA_AUTO_BATTLE` modes are gated in TWO places in `main.cpp`** —
    frontend-mash list and launcher list — or the boot hangs.

## Commands worth knowing

```powershell
# canonical
tools\gate.ps1                                   # everything CI runs, one command
tools\tune-report.ps1 -Compare base,turn=1456    # feel metrics sweep
tools\repin.ps1                                  # after an intentional sim change
tools\trace-diff.ps1 -A base -B friction=0.020   # first diverging tick

# fork
.\build.ps1 -Config rwdi -Soak 5                 # build + soak, fails unless green
.\tools\arena-log.ps1                            # summarise arena_bridge.log
.\tools\decomp-func.ps1 func_8001994C            # typed C for any function
.\tools\anim-contactsheet.ps1                    # 106 labelled pose PNGs -> tools\anims\
.\tools\rd-capture.ps1                           # RenderDoc frame, no keyboard

# gates
.\tools\arena-soak.ps1 -Mode 4  -Rising '\[animw\] \+\d+ idx=41 frame=(\d+)'  # set pose ANIMATES
.\tools\arena-soak.ps1 -Mode 10 -Rising '\[anim\] idx=32 frame=(\d+)'         # kick pose ANIMATES
.\tools\arena-soak.ps1 -AnimProbe                             # set pose still shown at +12
.\tools\arena-soak.ps1 -Mode 6 -Absent 'GUARD FIRED'          # must-never-happen
.\tools\arena-soak.ps1 -N 1 -Mode 7 -Expect '\[raster\] DONE'   # measure the floor

# runtime knobs, no rebuild
$env:ARENA_SET_ANIM='42'; $env:ARENA_KICK_ANIM='33'   # try the other pose
$env:ARENA_CAM_DIST='2400'; $env:ARENA_CAM_PITCH='30' # framing / angle
$env:ARENA_CAM_OFF='1'                                # A/B the camera on ONE binary
```
