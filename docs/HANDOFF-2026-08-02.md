## Traps that cost real time (new since 07-30 — older ones in that file)

- **The walker only re-asserts anims on its own state transitions**, not
  every frame (§8.18 as originally written oversold it). Three bugs from
  this: the airset clip persisting 26f, the eaten throw trigger, and the set
  clip looping after sets (#29 — where the 41 idling was ALSO the push-entry
  spam; §8.36 corrects §8.32's "pickup clip" attribution). The rule as of
  #29: verbs the walker sees (A, B) end themselves; verbs only the sim sees
  (R) need an explicit bridge handback.
- **A clip-keyed rule breaks silently when a new clip joins the family.**
  The charge-hide keyed on windmill 26; charge-run 28 arrived and the hide
  didn't know. Key family-wide rules on the STATE that selects the family
  (the hide now keys on the golden 62-tick timer).
- **The input POLL clock runs 2:1 against frames AND sim ticks.** Now
  structural: choreography lives in TICK-unit verb tables
  (`src/main/verb_script.h`) and the ×2 conversion exists in exactly one
  function. Never hand-convert again.
- **A poll-side tick stamp can lie by ~7 ticks on some boots** (§8.37): most
  boots deliver polls the same tick they're stamped, but ~1 in 6 delivers
  late — a `[verb]` marker stamped at injection then slices its window early
  against the anim stream. Markers are delivery-anchored now (flushed from
  `tick_input` with the consumption tick); the `[btn]` channel measures the
  pipeline whenever input timing is in question. Sim events themselves are
  tick-exact — when a marker and a sim event disagree, believe the sim event.
- **The spread fan fills the game's whole bomb pool [2..5]**; a set before
  it clears spawns NOTHING (silent `Get_InactiveObject` failure). One oracle
  run measured its stand-on-bomb segment over empty floor and the goldens
  "reproduced" **vacuously** — `[oracle-bomb]` going silent was the tell. A
  green re-measurement is only as good as the scene it measured.
- **The ground scan is not the push scan**: `damageState = OBJ_DEATH` blinds
  the 21E10-family interaction scan but NOT the walker's ground scan (it
  stood on door-class bomb actors at floor+210). Assume nothing transfers
  between the two.
- **`arena_bridge.log` truncates on EVERY boot** (fopen "w"). Copy a
  measurement log aside *immediately*; `oracle.ps1 -FromLog <copy>` re-parses
  without a 3-minute boot.
- **Goldens "byte-identity" is field-level**: the `provenance` block
  re-stamps `fork_commit`/`date` on every extraction, so whole-file compare
  is red-by-construction across commits. `oracle.ps1` compares measured
  fields only (both PowerShell editions serialize numbers differently, too —
  the compare normalizes).
- **`timelines.json` property order is load-bearing** — the emitter walks it
  as the temporal chain to resolve carried clips. Never hand-edit or sort it;
  regenerate with `oracle.ps1 -Force`.
- **`verb_script.h` sharp edges:** a row with `start == 0` never fires its
  marker (the poll counter is 1-based), and two rows sharing a name silently
  collapse to the first. The stick signs are inverted on purpose (-1 drives
  +Z) and the goldens depend on them — the comment on `stick_y` explains.
- **Adding a shared verb** is a documented procedure now (§8.35): both
  tables → rebuild → `oracle.ps1 -Force` (a new vanilla marker SPLITS the
  neighbour's window, so the neighbour's timeline legitimately changes) →
  raise `$AD_MIN_VERBS` → keep the battle window prefix-shaped or use a
  battle-only name.
